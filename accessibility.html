Accessibility

Accessibility statement

We want this website to be straightforward, readable and usable by as many people as possible.

How the site is designed

The site uses clear headings, large readable text, strong colour contrast, generous spacing, simple navigation and responsive layouts. Essential information is provided as text and does not depend on animation.

Keyboard and motion

The website can be navigated by keyboard. A skip link is provided, keyboard focus is visible, and reduced-motion preferences are respected.

Dementia-inclusive design

We have deliberately kept navigation and page structure simple. As the project develops, we want people living with dementia and carers to help us identify what makes the website easier to understand and use.

A work in progress

This is an early pilot website. Accessibility will continue to be reviewed as the project develops.

Tell us about a problem

If something is difficult to use or understand, please email likemanm@tcd.ie.
