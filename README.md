# Alongside — accessible prototype

A calm, accessible Bootstrap 5 prototype for a proposed Trinity community Alongside dementia-inclusive café pilot.

Version 2 incorporates material from the concept note, including:
- purpose: connection and reducing social isolation
- proposed audiences
- relaxed drop-in format
- optional music, reminiscence and creative engagement
- no requirement to disclose a diagnosis
- social rather than clinical support
- proposed small-group / 1.5–2 hour format
- accessible venue requirements
- bridge between lived experience, education and research

The site deliberately does not state that Trinity, TILDA or another organisation has approved or partnered with the pilot.

## Deploy
This is a static website. Upload the contents to GitHub Pages or Vercel.

## Accessibility display controls
Version 3 adds:
- larger text
- optional dyslexia-friendly font
- high contrast
- reset
- keyboard-accessible buttons with `aria-pressed`
- saved preferences using localStorage

### OpenDyslexic
For licensing/file-sharing reasons the font binaries are not included in this generated ZIP.
Copy **your own** `OpenDyslexic-Regular.woff2` and `OpenDyslexic-Bold.woff2`
from the font package you supplied into the site's `/fonts/` folder.
The CSS is already configured to use them. If they are absent, the control
falls back to Verdana/Arial.
